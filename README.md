# COM-3600F 필드 콘솔

コムシステム **COM-3600F 공기 이온 카운터**를 안드로이드 태블릿에서 직접 운용하기 위한 웹 콘솔.
노트북용 원본 프로그램(`C3600FEG.exe`, Visual Basic 6 · 32비트 Windows 전용)을 대체한다.

브라우저의 WebUSB로 FTDI USB-시리얼 변환 케이블을 직접 제어하므로 드라이버 설치나 루팅이 필요 없다.

## 장비 통신 규격

실측 파일 90개(44,000여 줄)를 대조해 역설계한 결과.

```
직렬     19200 bps · 8데이터 · 패리티 없음 · 1정지비트
샘플링   초당 1회 (900샘플 = 정확히 15분)

전송 형식 — 고정폭 14자 ASCII
  [0:3]   모드 태그  "M1-"   M=모드  1=레인지  -=극성(음이온)
  [3:7]   이온수, 우측정렬 4자   "****" = 측정범위 초과
  [7]     기온 부호  '-' 또는 ' '
  [8:14]  기온 ℃  "nn.nnn"

  예)  M1- 411- 2.976     411개/cm³, -2.976 ℃
       M1-8645 24.399    8645개/cm³, +24.399 ℃
       M1-**** 33.970    측정범위 초과, +33.970 ℃

종료 전문  EOF
```

원본 프로그램이 저장하는 파일은 각 줄을 큰따옴표로 감싼다(VB6 `Write #` 구문의 산물이며 회선에는 없다).
헤더와 꼬리말은 PC가 붙인다.

```
"[Date=26/03/07 Time=09:44:30 cdev=0 pWide=0 cBgn=0 xBgn=0]"
"M1- 411- 2.976"
...
"[ondo=0.5 situdo=71 ampm=M1- wCnt=900]"
```

`ondo`=기온, `situdo`=습도, `wCnt`=샘플 수. 습도는 전송 스트림에 없어 앱에서 직접 입력한다.

## 기능

- 실시간 음이온 농도 · 기온 · 극성 · 레인지 · 측정범위 초과 표시
- 최소 / 최대 / 평균 / 표준편차
- 음이온·기온 이중축 실시간 그래프
- 목표 샘플 대비 진행률, 경과·잔여 시간, 결측 카운트
- 수신 전문 원문 모니터 (연결 진단용)
- 저장: 원본 `.txt` 한 가지. 원본 프로그램의 파일 필터도 측정 데이터는
  `0*.txt;1*.txt;2*.txt` 하나뿐이었다 (`.jpg`는 화면 캡처, `.hft`는 리포트 서식,
  `.ini`는 설정용으로 데이터와 무관)
- 기존 측정 파일 열람 (원본·한글 표 두 형식, EUC-KR 자동 처리)
- 측정 보관함 (오프라인 유지)

## 준비물

- 안드로이드 11 이상 · 크롬
- 기존 RS-232C ↔ USB 변환 케이블 (FTDI 계열)
- USB-C ↔ USB-A(암) OTG 젠더

## 미확인 사항

측정 시작 명령은 확인하지 못했다(도움말 파일 `C3600FEG.chm` 추출 실패).
장비가 자체적으로 값을 흘려보내는 방식이면 명령 없이 동작하며, 필요할 경우 설정에서 지정할 수 있다.
